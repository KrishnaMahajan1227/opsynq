# Solarize ERP — V6 Upload Excel redesign

- Upload Excel is now part of the same Admin/Superadmin enterprise shell instead of a disconnected centered card.
- Full role-aware sidebar navigation is available directly from the upload workspace.
- Farmer import and JSR bulk update are separated into two clear workflows with consistent file selection, validation and processing states.
- Selected workbooks show filename and file size; file removal is one click.
- Duplicate handling and all existing backend endpoints remain unchanged.
- JSR result feedback is presented in a structured summary + attention table.
- Responsive behaviour uses the same compact sidebar rail pattern to avoid overlap/clipping.
- No new npm dependencies were added.
