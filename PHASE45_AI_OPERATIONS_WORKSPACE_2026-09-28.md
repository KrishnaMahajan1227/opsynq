# Phase 45 — AI Operations workspace stabilization

- AI Operations is a dedicated first-class navigation group.
- Backend accepts either `AI_PROVIDER_API_KEY` or the existing `GEMINI_API_KEY`; browser code receives neither secret.
- Proposal rows are clickable and open a detail drawer with rationale, prepared action, source entity, timestamps and decision audit.
- Proposal drawer and table can navigate to the relevant operational module before manual confirmation.
- Manual confirmation remains mandatory for controlled actions.
- Operations brief scope cards, question field and actions now use the shared professional UI system rather than browser-default controls.
