# Phase 16 Local Test

1. Run `npm run qa:release`.
2. Start backend with `npm run backend`.
3. Start both frontends with `npm run frontend`.
4. Sign in and open a Company workspace.
5. Collapse the desktop sidebar. Confirm the edge Expand button remains visible and restores the full sidebar.
6. Expand/collapse each main heading and refresh. Confirm state is remembered.
7. Search for a module using the sidebar search and Ctrl/Cmd + K.
8. Open My Workspace, pin several modules, navigate to them, and confirm Recent Modules updates.
9. Resize below 760px and confirm navigation becomes a drawer with backdrop and close control.
10. Navigate through all module groups and confirm no content is clipped or hidden.
